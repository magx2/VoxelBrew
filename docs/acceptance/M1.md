## Exact reproduction

After the native bootstrap from the README, Windows PowerShell:

```powershell
.\gradlew.bat check
.\gradlew.bat :cli:installDist
powershell -NoProfile -ExecutionPolicy Bypass -File scripts\reference-part.ps1 -Destination build\demo\new-reference.vxb
.\cli\build\install\cli\bin\cli.bat inspect fixtures\reference-8mm.vxb --point 10,10,4
```

Ubuntu:

```bash
./gradlew check
./gradlew :cli:installDist
bash scripts/reference-part.sh build/demo/new-reference.vxb
cli/build/install/cli/bin/cli inspect fixtures/reference-8mm.vxb --point 10,10,4
```

Use an unused destination for the script. It exercises the public commands in
separate processes, including save/close/reopen, edit, inspection and rollback.
WSL validation ran in `/tmp/voxelbrew-m0` using a separate Ubuntu build of the
same source; both OSes used their own native runtime libraries.

## Additional automated evidence

* CAD-01 engine/CLI subset: XY and +12 mm offset planes round-trip with stable
  IDs and expected Z extents; signed circle extrusion −3 gives [9,12] mm.
* CAD-02: diameter 4→6 retains the center; zero, negative, NaN and infinity
  identify the feature/field and leave the prior valid revision untouched.
* CAD-04/05 engine/CLI subsets: through-hole after thickness change, rollback,
  forward replay, dimension undo/redo and independent timeline cursor.
* CAD-06: a saved missing-input fixture reopens with a failed extrusion and
  blocked cut; geometry access/full-part export guard refuses the result;
  reference repair restores it without duplicating features.
* Failed geometric cut preserves editable definitions and can be undone.
* Truncated header/payload and checksum corruption have useful diagnostics.
* Newer schema and unknown Protobuf fields are protected from destructive writes.
* Concurrent create-if-absent saves publish one complete file and preserve the
  winner; failed writes clean temporary siblings.
* Shared offset-plane edits are one transaction; the origin plane is fixed.

## Resolved failures and limits

An intermediate Windows run failed two newly added history tests after their
matching engine changes were made while the earlier run was still executing.
The finished source was rebuilt and the entire check rerun successfully.
The pinned Protobuf Gradle plugin emits an upstream Gradle-10 deprecation
warning; the pinned Gradle 9.1.0 build and tests pass.

These are automated/headless checks and command-script verification. GUI
gestures and GUI/CLI parity (CAD-03/CAD-07), split bodies (CAD-08), mesh/export
contracts, plugin loading, print setups, slicers, supports and hardware tests
remain later-milestone work. No macOS, hosted-CI or installer qualification is
claimed. The CLI development distribution requires an installed Java 21 JVM.
