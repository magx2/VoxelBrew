# M8 — expanded sketch geometry types

The [audited inventory](../sketch-types.md) links Autodesk's current geometry
families and describes the implemented variants and deliberate limits. Engine
owns all constructors, spline interpolation, constraints and persistent glyph
outlines; CLI and JavaFX call the same operations. Native wires preserve exact
ellipse, rational-conic, B-spline and Bezier curves. Separate regions become
independent solids without relaxing the single-solid native ownership rule.

## Automated coverage

- `SketchCurveTypesTest`: analytic ellipse/conic positions and curvature,
  spline interpolation, periodic endpoint continuity, both control degrees,
  indexed point references/dragging and invalid inputs.
- `SketchToolsTest`: every rectangle/circle/arc/polygon/slot construction
  variant, tangent branches, signed sweeps, side choice, retained slot
  constraints and new driving dimensions.
- `SketchCurveTypesIntegrationTest`: independent analytic ellipse/conic/slot
  volumes, exact closed spline solids, slot width edits, text with holes and
  separate bodies, font-outline persistence, associative path changes and
  native handle cleanup. Existing schema compatibility covers versions 1–4.
- `WorkflowTest.newSketchTypesAndTextPersistAcrossFreshProcesses`: ellipse
  dimensions, curved slot, closed fit spline, editable text, stable document
  identities, rejected-write byte preservation and multi-body 3MF export.
- `WorkbenchUiTest.ellipseSlotsAndConicsUseRealSketchTools`: actual canvas and
  numeric input, new dimensions, exact combined volume, multiple bodies and
  save/reopen.
- `WorkbenchUiTest.fitControlSplinesAndTextUseRealSketchTools`: closed fit and
  degree-5 control splines, indexed control dragging and undo, text editing,
  four-body extrusion, global history, files and independent CLI inspection.
- `WorkbenchUiTest.tangentCirclesAndAssociativeTextPathsUseRealControls`:
  selected tangent lines, circle branch, text on an arc, geometry-following
  behavior, detach/undo, extrusion and draft cancellation.

Focused engine/CLI checks passed on Windows with real OCCT. The three new
Robot workflows passed in the separate Ubuntu 24.04 WSL2 checkout under
Xvfb/Mesa. Screenshot review covers light/dark palettes and the new selector.
The first spline/text interaction run exposed a test attempting Undo after
reopening (which intentionally resets session history); the test now checks
Undo/Redo before reopen and separately verifies the reopened document.

xvfb-run -a -s "-screen 0 1600x1000x24" env LIBGL_ALWAYS_SOFTWARE=1 ./gradlew check
