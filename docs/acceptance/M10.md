# M10 — JSR 385 units and quantities

[Unit architecture and usage](../units.md) describe the standard API, pinned
implementation, typed boundaries and preserved numeric/persistence contracts.

## Automated coverage

- `MeasurementsTest`: standard quantity interoperability, metric/imperial
  conversions, area/volume/time/mass/speed, dimensionless percentages,
  Celsius/Kelvin offsets, angle-kind separation, unit algebra and power bounds,
  typed process/mesh settings, display conversion and legacy parameter names.
- `MeasurementIntegrationTest`: typed feature/kernel inputs and edits, exact
  reference part volume and hole, bounds, tessellation, mismatched-unit rejection
  without a transaction, and a schema-6 document produced before this migration
  that reopens and saves byte-for-byte unchanged.
- Existing parameter/controller suites cover formula dependencies, variants,
  local/global history, cancellation, failed rebuild/export guards and stale results.
- The independent `SpacerProvider` fixture imports `javax.measure.Quantity`
  through the published engine API and uses typed native geometry inputs.
- The CLI parameter/configuration workflow now uses centimeter display units
  and verifies 60/80 mm geometry, fresh-process persistence and export.
- Robot's complete parameter workflow now creates a 6 cm sketch-width parameter
  inside the sketch, overrides it to 8 cm and keeps extrusion in millimeters.
  The repair workflow rejects an angle unit substituted for a bound length.
  Existing full GUI cases exercise every migrated degree/radian boundary.
- Root checks exercise real OCCT, independent export readers, real PrusaSlicer,
  standalone consumers and packaged CLI/GUI launchers with runtime dependencies.

The compatibility fixture `engine/src/test/integrationTest/resources/parameters/schema6-configurations.jcad`
was generated by M9's GUI workflow at commit
`73773c0561038afa195a060549a61eb3673904ef` (Large 80 × 40 × 8 mm; Default 60 × 40 × 5 mm).
It contains stable constrained-sketch features, named parameters and overrides.

## Commands and evidence

Windows full gate: `gradlew.bat check`, without exclusions.

Ubuntu full gate in a separate Linux checkout:

```sh
xvfb-run -a -s "-screen 0 1600x1000x24" env LIBGL_ALWAYS_SOFTWARE=1 ./gradlew check
```

Focused WSLg run:

```sh
LIBGL_ALWAYS_SOFTWARE=1 ./gradlew :engine:integrationTest \
  --tests '*MeasurementIntegrationTest' :gui:e2eTest \
  --tests '*namedSketchParametersAnd3dConfigurationsDriveOneDesign' \
  --tests '*parameterRepairRenameAndSketchCancellationUseRealControls'
```

Reports live in module `build/reports/tests` and `build/test-results`; screenshots
are under `gui/build/ui-artifacts`. Logs use `.tools/units-*.log`. Preserved
evidence uses `.tools/units-wsl-evidence`, `.tools/units-local-windows` and
`.tools/units-hosted-windows`; exact final revision, results, counts and hosted
links are recorded in `.tools/units-qualification.json` and reported at handoff.

Local Windows previously lacked JavaFX SCENE3D. Its full command result is
recorded separately from full hosted Windows qualification. macOS GUI remains
deferred; the existing CI matrix includes its headless workflows and packages.
Hosted artifact retention stays three days.
