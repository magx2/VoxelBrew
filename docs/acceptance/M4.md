Prusa's CLI `--merge` retains separate objects; it is not equivalent to the GUI's
multipart import. Use the supplied vendor project, or explicitly import STLs as
one multipart assembly. The automated handoff uses independent STL readback into
that assembly before the real receiver slices it; direct multi-file CLI import
is not claimed to preserve a stacked assembly.

organic/tree supports, painted regions and multiple materials. Custom closed
pillars satisfy the first-release support-mesh requirement. Bambu Studio
compatibility remains pending until the receiver check. No physical print claim.

## Slicer UI maintenance — 2026-11-10

The Slicer workspace retains its body colors and adds black CAD face edges in
2D/3D placement views. Plates have individual close controls (disabled for the
last plate) and support drag reordering. The selected object's floating label
contains its removal control. Placement, process, support and printer controls
use the available sidebar width; redundant duplicate, face-ID, process-apply and
job-export controls are removed. Process edits apply on Enter/focus loss or
choice changes. New workspaces default to replacing jobs; starting a slice opens
the Job tab. File > Export remains the export entry point.

Automatic orientation evaluates feasible planar bed faces off the UI thread and
ranks unsupported area, bed contact and height in that order. This is a geometric
heuristic, not a guarantee of optimal print strength or finish. Results from an
outdated document revision are discarded.

### Master support switch — 2026-11-10

The Supports tab now exposes **Enable supports**. Its persistent, project-wide
`PrintSetup.supportsDisabled` flag excludes automatic/manual supports and rafts
from detached manufacturing views without deleting editable definitions. The
additive Protobuf field defaults to false for existing documents; older readers
reject the unknown field when enabled rather than silently losing this setting.
Plate/profile/workspace edits and plate reordering preserve the flag.
