# M4 acceptance — split, placement and printer jobs

**Status: done for the first-printable release**, implemented in `af09202` and
confirmed by the Windows/Ubuntu and independent viewer evidence below. The user
accepted this scope on 2026-11-05. Additional capabilities (adaptive layers,
generated automatic support meshes and advanced supports) remain tracked below;
they are not prerequisites for this first-printable milestone. M5 packaging and
M6 feature plugins have separate acceptance records.

Reference setup requested by the user: generic printer, 0.4 mm nozzle, PLA and
PETG. Implemented reference profile: generic Marlin 2, 200×200×200 mm, no bed
exclusions, 1.75 mm filament, text G-code. **Physical hardware unverified.**
PrusaSlicer Windows 2.7.2+win64-202402291307; Ubuntu package
2.7.2+dfsg-1build2 (`PrusaSlicer-2.7.2+UNKNOWN`).

Prusa's CLI `--merge` retains separate objects; it is not equivalent to the GUI's
multipart import. Use the supplied vendor project, or explicitly import STLs as
one multipart assembly. The automated handoff uses independent STL readback into
that assembly before the real receiver slices it; direct multi-file CLI import
is not claimed to preserve a stacked assembly.

Unsupported capabilities: adaptive layers, generated automatic support meshes,
organic/tree supports, painted regions and multiple materials. Custom closed
pillars satisfy the first-release support-mesh requirement. Bambu Studio
compatibility remains pending until the receiver check. No physical print claim.
