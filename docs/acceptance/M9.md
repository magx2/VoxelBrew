# M9 — named parameters and configurations

The [parameter workflow](../parameters.md) describes the engine-owned expression
grammar, supported dimensions, configuration inheritance, CLI commands and
limits. Parameters, stable IDs, bindings, overrides and the active configuration
persist in schema 6; versions 1–5 remain readable.

## Automated coverage

- `ParametersTest`: arithmetic, precedence, length/angle conversions, implicit
  units, functions, expression bounds, dependency cycles/missing names, bad
  inactive overrides, reference-safe renaming (including scientific notation),
  inheritance/copy behavior, unit-error transaction preservation, undo/redo and
  rollback independence.
- `ParameterIntegrationTest`: real OCCT reference part at 5/8 mm, stable IDs and
  persistence, exact 19099.469035085127 mm³ volume and open hole, shared planes,
  signed extrusion, split offsets, simultaneous constrained dimensions, invalid
  variant repair, and rectangle/circle position bindings through legacy sketch
  conversion. Numeric alias edits detach the canonical constraint binding.
- `SketchControllerTest`: local draft parameter/binding history and repairable
  formula errors. Existing stale-solve tests still exercise worker sequencing.
- `DocumentControllerTest`: formula extrusion previews/cancellation, one-step
  commit/undo/redo, configuration rebuilds, and failed-variant geometry/export
  guards. Existing document/revision tests cover coalescing and stale rejection.
- `WorkflowTest.namedParametersAndVariantsPersistAcrossProcessesAndExport`:
  separate-process parameter/configuration changes, legacy conversion, rename,
  rejected-write preservation, stable IDs and active-configuration 3MF export.
- `WorkbenchUiTest.namedSketchParametersAnd3dConfigurationsDriveOneDesign`:
  parameters created inside a sketch, formula and numeric dimensions, formula
  extrusion, configuration table editing/activation, history, save/reopen and
  independent CLI volume inspection through actual Robot controls.
- `WorkbenchUiTest.parameterRepairRenameAndSketchCancellationUseRealControls`:
  manager errors/Cancel, bound-name rewrite, sketch draft cancellation, binding
  conversion on Finish, failed variant/export refusal and recovery in light mode.

## Reproduction and evidence

The initial full Ubuntu run caught a compatibility regression in the existing
invalid-dimension interaction: `NaN` was classified as an unknown parameter.
Nonfinite numeric literals now retain the finite-number diagnostic, and their
names are reserved. The focused repair check and complete root gates are rerun
after this fix; the rejected edit never changed the document.

Full Windows root command: `gradlew.bat check`, with no exclusions.

Full Ubuntu command in the independent filesystem checkout:

```sh
xvfb-run -a -s "-screen 0 1600x1000x24" env LIBGL_ALWAYS_SOFTWARE=1 ./gradlew check
```

Focused WSLg gestures:

```sh
LIBGL_ALWAYS_SOFTWARE=1 ./gradlew :gui:e2eTest \
  --tests '*namedSketchParametersAnd3dConfigurationsDriveOneDesign' \
  --tests '*parameterRepairRenameAndSketchCancellationUseRealControls'
```

Reports are under each module's `build/reports/tests/{test,integrationTest,e2eTest}`.
Screenshots in `gui/build/ui-artifacts` include `parameter-configurations-dark.png`
and `parameters-light.png`; the CLI transcript is `parameter-cli-inspection.txt`.
Local commands/logs use `.tools/parameters-*.log`; preserved Linux reports and
platform details use `.tools/parameters-wsl-evidence`. Hosted full Windows
reports use `.tools/parameters-hosted-windows`. Final exact commit, gate results,
counts and hosted URLs are recorded in `.tools/parameters-qualification.json`
and reported at handoff; these generated files remain outside source control.

Local Windows has previously reported no available JavaFX 3D device. Its full
root result is recorded explicitly; it is not treated as a GUI pass. Full Windows
qualification uses `full-check.yml` on `windows-2022` at the pushed revision.
Routine CI covers Ubuntu/Windows GUI and packages and macOS headless/package
checks. macOS GUI remains deferred; hosted artifacts retain three days.
