# M2 — tessellation, mesh export and independent plugins

Date: 2026-11-04 (Europe/Warsaw). Input: committed M1 reference-8mm.vxb.
Both Windows 11 x86-64 and Ubuntu 24.04.3 x86-64 / WSL2 passed the full root
`check` with no exclusions: 7 native, 11 editable-engine, 5 export and 3 CLI
tests, **26 passed per platform**, none skipped. OCCT remains 7.9.0; TKMesh
was added to the locked toolchain. The independent provider reported 592
triangles at the default tessellation settings on both OSes.

## Reproduction

```powershell
.\gradlew.bat check :cli:installDist
.\cli\build\install\cli\bin\cli.bat exporters --plugin-dir "build\m2-demo\plugins with spaces"
.\cli\build\install\cli\bin\cli.bat export fixtures\reference-8mm.vxb --format 3mf --output build\m2-demo\reference.3mf --overwrite
```

```bash
./gradlew check :cli:installDist
cli/build/install/cli/bin/cli exporters --plugin-dir 'build/m2-demo/plugins with spaces'
cli/build/install/cli/bin/cli export fixtures/reference-8mm.vxb --format 3mf --output build/m2-demo/reference.3mf --overwrite
```

Create the demo directory and copy the independently built
`fixtures/exporter-plugin/build/libs/fixture-exporter-1.0.jar` into its plugin
directory before the listing command. Windows and WSL use separate build trees.
Full local logs: `.tools/m2-windows-check.log` and Ubuntu
`/tmp/voxelbrew-m0/.tools/m2-linux-check.log`.

## Verified evidence

- Tessellations remain usable after native owners close, preserve exact B-rep
  volume/bounds, carry per-triangle face IDs and respond to tolerance changes.
- Independent binary STL and XML/ZIP 3MF readers verify finite coordinates,
  consistent closed meshes, scale, relationships, units, identity and placements.
  STL translation is applied once. 3MF shares one resource between two instances;
  the rotated/translated instance has bounds (60,20,3) to (100,80,11) mm.
- The reference mesh matches bounds within 0.001 mm, exact volume within a
  separately chosen 0.5 mm^3 mesh tolerance, and mid-height hole contour radial
  deviation within 0.021 mm. Exact solid acceptance stays at 0.01 mm^3.
- Consumer-built plugin discovery works from paths containing spaces. A
  nondefault `label` option reaches the installed CLI provider on both platforms.
  Duplicate IDs, API 999, a missing provider class, failed writes and existing
  destinations produce diagnostics. Partial output never replaces existing data.
- CLI export rejects rollback and preserves an existing destination. Engine
  export rejects failed evaluation, invalid options and open meshes.

XML results and installed CLI transcripts are in [M2/](M2/). The initial check
exposed an overly restrictive ID validator rejecting `3mf`; it was fixed and
the full checks passed again. Bambu Studio dimensions/layer-preview verification
is **pending**. macOS, GUI interaction, print setups, slicers and hardware are
